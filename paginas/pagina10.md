## 👩‍🏫 Guía didáctica para el profesorado

### Recomendaciones generales

1. **Antes de empezar:** Asegúrate de que las tablets funcionan, las apps están actualizadas y tienes conexión wifi estable.

2. **Atención a la diversidad:** Los pictogramas son el apoyo principal. Para alumnado con más dificultades, reduce a 2 pasos la secuencia inicial.

### 📊 Relación de tareas con criterios de evaluación

| Tarea | Criterio | Instrumento |
|-------|----------|-------------|
| Identificar problemas | CD.1.1 | Lista de cotejo |
| Aprender secuencia | CD.1.2 | Lista de cotejo |
| Simular fallos | CPSAA.2.1 | Observación directa |
| Crear pasaporte | CCL.1.1 | Rúbrica del pasaporte |
| Exponer | CCL.2.1 | Rúbrica del pasaporte |
| Autoevaluarse | CPSAA.3.1 | Autoevaluación con pictogramas |

### ♿ DUA aplicado en este proyecto

| Principio DUA | Cómo se aplica |
|---------------|----------------|
| **Representación** | Pictogramas, instrucciones orales, demostración práctica, vídeos tutoriales |
| **Acción y expresión** | Los alumnos pueden mostrar su aprendizaje dibujando, señalando, verbalizando o grabando audio |
| **Implicación** | El juego de "ser técnico" y el pasaporte aumentan la motivación |

### 📝 Observaciones para la implementación

- **Duración real:** Prevé 5-10 minutos adicionales para imprevistos.
- **Alumnado con NEAE:** Añade una tarjeta visual con la secuencia en su mesa.
- **Evaluación formativa:** Usa la lista de cotejo en tiempo real para ajustar tu intervención.
- **Familia:** Envía la hoja informativa al inicio del proyecto.
