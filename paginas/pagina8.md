## 📊 Criterios de evaluación

### Relación de tareas con criterios

| Tarea | Criterio de evaluación | Agrupamiento | Tiempo |
|-------|------------------------|--------------|--------|
| **Tarea 1:** Identificar problemas técnicos | CD.1.1. Identificar problemas técnicos sencillos | Gran grupo + pequeño grupo | 30' |
| **Tarea 2:** Aprender los 4 pasos | CD.1.2. Aplicar secuencia básica de resolución | Parejas | 30' |
| **Tarea 3:** Simular fallos y regular emociones | CPSAA.2.1. Gestionar la frustración | Individual + pequeño grupo | 30' |
| **Tarea 4:** Crear el Pasaporte Digital | CCL.1.1. Usar frases para describir un problema | Individual (con apoyo) | 30' |
| **Tarea 5:** Exponer el pasaporte | CCL.2.1. Exponer un trabajo propio | Individual | 15'/alumno |
| **Tarea 6:** Autoevaluación | CPSAA.3.1. Reflexionar sobre el aprendizaje | Individual | 10' |

---

### Descripción de los criterios

| Código | Descripción |
|--------|-------------|
| **CD.1.1.** | Identificar problemas técnicos sencillos en dispositivos digitales y nombrarlos con vocabulario básico. |
| **CD.1.2.** | Aplicar una secuencia básica de resolución de problemas técnicos siguiendo instrucciones visuales. |
| **CPSAA.2.1.** | Gestionar la frustración ante imprevistos usando estrategias básicas de regulación emocional. |
| **CCL.1.1.** | Usar frases sencillas para describir un problema y pedir ayuda con lenguaje claro. |
| **CCL.2.1.** | Exponer de forma sencilla un trabajo propio manteniendo la atención del interlocutor. |
| **CPSAA.3.1.** | Reflexionar sobre el propio aprendizaje identificando lo aprendido y lo que necesita mejorar. |
